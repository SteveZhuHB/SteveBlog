# Small Solid Steps (S³)

Steve Zhu's personal tech blog and **Data in Motion** project portfolio: <https://stevezhuhb.github.io/SteveBlog/>

Built with [Astro](https://astro.build) and deployed to GitHub Pages by GitHub Actions.

```sh
npm install
npm run dev            # http://localhost:4321/SteveBlog/
npm run check:public   # scan for anything that must not be published
npm run build          # static site in dist/
```

How a post goes from a private project to this site: [PUBLISHING.md](PUBLISHING.md).
